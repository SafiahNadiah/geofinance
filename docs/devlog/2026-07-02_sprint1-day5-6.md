## 3. Verification Steps

### 3.1 Start frontend via Docker Compose

```powershell
docker compose up frontend
```

Frontend container built and started; Next.js dev server came up
without errors.

### 3.2 Browser check

Opened `http://localhost:3000` — landing page rendered correctly.

### 3.3 Console check

Browser DevTools console showed:
```
Download the React DevTools for a better development experience...
[HMR] connected
Unable to add filesystem: <illegal path>
```

All three are benign:
- React DevTools message — informational only, not an error
- `[HMR] connected` — **confirms** the Next.js dev server and Hot
  Module Reload are working correctly
- `Unable to add filesystem: <illegal path>` — traced to a browser
  extension (not application code); confirmed harmless by re-checking
  in an Incognito window, where the message did not appear

No application-level errors present.
