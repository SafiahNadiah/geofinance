## 2. Migration Tool Decision

`docs/02_SRS.md` left the migration tool as an open decision between
`node-pg-migrate` and Prisma Migrate. **Chose `node-pg-migrate`** —
reasoning: `03_DATABASE.md`'s table definitions are already written in
raw-SQL-style terms (explicit `GEOMETRY(Point,4326)` types, `CHECK`
constraints), and `node-pg-migrate` maps to that directly without
fighting an ORM's schema DSL over PostGIS-specific types.

This decision closes the open item flagged in `03_DATABASE.md §6`
("Migration Strategy").

Also present (expected, not app tables): `pgmigrations` (migration

with the `postgis/postgis` image.
