## 2. What Was Built

### 2.1 Backend project initialized

- `backend/` set up as a TypeScript + Express project
- `tsconfig.json` with **strict mode enabled**, per the binding coding
  standard in `docs/04_AGENTS.md §4`

### 2.2 Folder structure (Clean Architecture, per `02_SRS.md §2.3`)

```
backend/
└── src/
    ├── domain/                  # Entities, value objects — no framework imports
    ├── application/
    │   ├── services/            # Business logic (empty for now)
    │   └── dtos/                # Request/response DTOs (empty for now)
    ├── infrastructure/
    │   ├── repositories/        # DB access (empty for now)
    │   ├── geoserver/           # GeoServer client (empty for now)
    │   └── db/                  # Connection, migrations runner (empty for now)
    ├── interfaces/
    │   ├── controllers/         # HTTP handlers — thin, delegate to services
    │   ├── routes/               # Express route registration
    │   └── middleware/           # Auth, RBAC, validation, error handling (empty for now)
    └── shared/                    # Errors, config, logger (empty for now)
```

Empty folders were seeded with placeholder files so they're tracked
by git (folders themselves aren't tracked by git if empty).

### 2.3 First endpoint — health check

- `GET /health` implemented following the layering rule from
  `04_AGENTS.md §4`: route registered in `interfaces/routes/`, handled
  by a thin controller in `interfaces/controllers/` with no logic
  beyond returning the response — no business logic in the route
  handler itself.
- Returns `{ "status": "ok" }` with HTTP 200.

### 2.4 Dockerfile

- Added `backend/Dockerfile`, matching what `docker-compose.yml`
  already expected (`build: context: ./backend`)
- Listens on the `PORT` environment variable (default `3001`, per
  `docker-compose.yml`'s `BACKEND_PORT`)

### 2.5 Documentation

- `backend/README.md` added with local run instructions, both via
  Docker and directly with `npm run dev` (for faster iteration without
  rebuilding the image every change)
